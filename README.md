## English

### ✨ What's here

This repository is what Community Applications reads: the Docker templates and plugin entries for every app below. Each app's code lives in its own repository.

| App | Type | Template | Project |
|---|---|---|---|
| HAPass Invitations | Docker | [`templates/ha-pass-invitations.xml`](templates/ha-pass-invitations.xml) | [ha-pass-invitations](https://github.com/Nebur692/ha-pass-invitations) |

| ZITADEL | Docker | [`templates/zitadel.xml`](templates/zitadel.xml) | [unraid-sso-templates](https://github.com/Nebur692/unraid-sso-templates) |

| oauth2-proxy | Docker | [`templates/oauth2-proxy.xml`](templates/oauth2-proxy.xml) | [unraid-sso-templates](https://github.com/Nebur692/unraid-sso-templates) |
| Zabbix Agent 6 LTS | Plugin | [`plugins/zabbix_agent.xml`](plugins/zabbix_agent.xml) | [unraid-zabbix_agent-6lts](https://github.com/Nebur692/unraid-zabbix_agent-6lts) |

### 📦 Installation

Search for the app in **Apps** (Community Applications). Until it is listed, a Docker template can be added by hand: **Docker → Add Container → Template repositories**, paste `https://github.com/Nebur692/unraid-community-apps`, save, and pick it from the template list.

### 💙 Support

Each app has its own support thread, linked from its template. General thread: [Unraid templates by Nebur692](https://forums.unraid.net/topic/200036-unraid-templates-nebur692/).

### 📜 License

The templates and plugin entries in this repository are [MIT](LICENSE). Each app keeps the license of its own project.

### 📦 Instalación

Busca la aplicación en **Apps** (Community Applications). Mientras no esté publicada, una plantilla de Docker se puede añadir a mano: **Docker → Add Container → Template repositories**, pega `https://github.com/Nebur692/unraid-community-apps`, guarda y elígela de la lista de plantillas.

### 💙 Soporte

Cada aplicación tiene su propio hilo de soporte, enlazado desde su plantilla. Hilo general: [Unraid templates by Nebur692](https://forums.unraid.net/topic/200036-unraid-templates-nebur692/).
